Giới thiệu

Trang web nhỏ dùng để luyện tập quản lý mã nguồn với Git: commit, tạo nhánh, gộp nhánh và đẩy lên GitHub.

Các bước thực hành

  1. Khởi tạo repository và kết nối với GitHub
  2. Commit đầu tiên với README.md và index.html
  3. Tạo nhánh feature/them-giao-dien và thêm style.css
  4. Gộp nhánh vào main và push lên GitHub
